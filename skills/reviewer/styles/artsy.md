# Artsy

A good artsy clip has a mood: a deliberate rhythm, a graded look, and a line that stays with you.

- Slower pacing, pauses, sparse captions and an open-ended ending are right here; don't send it back for them.
- Send it back (off_style) if it looks like a plain talking-head cut: ungraded colour, dense captions, quick functional cuts.
- It still needs to hold attention: a pause must feel chosen, not like dead air, and the opening line must intrigue.
