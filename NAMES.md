# Name ideas

Name brainstorm for a self-improving video editing system, built for the AIE Code Summit 2026 Hackathon, track "The System That Gets Better". Several models brainstormed in parallel, each from a different angle. ★ marks each model's own top picks.

## Chosen direction: SIsyphus

In names written like "SIsyphus", the capital **SI** stands for **Self-Improving**.

In the myth, Sisyphus pushes a boulder uphill and it rolls back every time. This system keeps what works: changes that fail the held-out evaluation roll back, and changes that pass stay. *SIsyphus, but the hill gets shorter.*

Tagline: ***"One must imagine SIsyphus editing."*** (after Camus: "One must imagine Sisyphus happy.")
