# Research

Background research behind product decisions, kept so the numbers in the skill files have a source.

- `short-form-editing-styles.md` (2026-11-07): how TikTok, Reels and Shorts clips are edited, which named styles exist, and how they map to the edit plan's knobs. The editing styles in `skills/*/styles/` and the margins in `engine/sisyphus_engine/render.py` were calibrated from it (#26). The researchers' raw notes, with every source cited inline, are in `short-form-editing-styles-notes/`.

Most of the sources are blogs by caption and clipping tool vendors with undisclosed methods, so treat the figures as starting points for the Auditor's A/B, not measurements.
