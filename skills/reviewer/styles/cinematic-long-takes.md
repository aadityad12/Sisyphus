# Cinematic long takes

A good clip in this style has a cinematic mood: long deliberate takes, one consistent grade, and a line that stays with you.

- Slower pacing, pauses, sparse captions and an open-ended ending are right here; don't send it back for them.
- Send it back (off_style) if it looks like a plain talking-head cut: ungraded colour, dense or all-caps captions, quick functional cuts, punch-ins.
- It still needs to hold attention: a pause must feel chosen, not like dead air, and the opening line must intrigue. Slowed-down speech is not mood; send that back too.
